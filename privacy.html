Privacy Policy

Mail.ru Calendar Sync uses calendar event details and identifiers only to read Mail.ru events and create, update or remove their copies in Google Calendar. Google access is granted through OAuth.

Access credentials and synchronization records are stored locally. Calendar data is exchanged with Mail.ru and Google for synchronization. Optional Telegram notifications contain operational status. Data is not sold, used for advertising or used to train AI models. This website receives no calendar data; GitHub processes ordinary hosting request metadata.

Data remains until removed by the owner or synchronization. Access can be revoked in Google account settings; revocation does not delete existing calendar copies. Local records and imported events can be removed separately.

Contact: GitHub profile. Do not post private data publicly.
