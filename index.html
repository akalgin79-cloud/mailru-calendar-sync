Mail.ru Calendar Sync

A personal Windows application that synchronizes calendar events from a user's Mail.ru calendar to a separate calendar in their Google account.

The application runs locally on the owner's computer. It reads Mail.ru events and creates, updates or removes their imported counterparts in Google Calendar. It does not modify the source Mail.ru calendar.

Google Calendar access is requested through Google's OAuth consent screen. The application uses this access only to maintain the calendar copy. Optional Telegram notifications report synchronization failures and recovery.

This website provides application information only. It does not connect to calendars, request passwords or accept uploads of calendar data.
